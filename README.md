# NIT RR Scholar Hub 🎓

A free, centralized academic resource platform designed and curated specifically for the student body at NIT Raipur.

🔗 **Live Website:** [Visit Scholar Hub](https://astrobiopedia-navonmesh.my.canva.site/nit-raipur-scholar-hub-by-navonmesh)

---

## 📌 Project Overview
The goal of this platform is simple: save time, reduce academic stress, and help engineering students focus on learning instead of chasing study materials.

## 📚 What's Inside
* **1st Year:** Complete subject-wise notes.
* **2nd, 3rd & 4th Year:** Semester-wise structured engineering materials.
* **Examinations:** Previous Year Questions (PYQs) with verified solutions.
* **Lab & Reference:** Complete lab manuals, assignments, and digital textbooks.

## 🛠️ Tech Stack & Tools
* **Design & Layout:** Canva Website Builder
* **Asset Management:** Cloud Storage Integration (Google Drive)
